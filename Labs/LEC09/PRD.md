# Sonic 애니메이션 뷰어 PRD

## 1. 제품 개요

`sonic-sprite.png`의 Sonic 동작을 순서대로 재생하는 데스크톱 뷰어다. 이동 동작은 애니메이션과 화면 위치를 함께 바꾸고, 첫 번째·세 번째·네 번째·마지막 동작은 중앙에서 재생한다.

### 사용자 시나리오

사용자는 프로그램을 실행하고 별도의 조작 없이 확대된 Sonic 애니메이션 전체 순환을 관찰한다. 이동 동작에서는 캐릭터가 좌우로 이동하고, 점프 동작에서는 수직 궤적을 그린다. 한 동작은 5회 재생되고 마지막 프레임과 위치에서 1초간 멈춘 다음 다음 동작으로 넘어간다.

### 개발 환경 및 산출물

- 언어 및 라이브러리: Python, `pico2d`
- 실행 소스: `Labs/LEC09/sonic_animation_viewer.py` 단일 파일
- 입력 이미지: `Labs/LEC09/sonic-sprite.png`
- 화면 크기: 1200 × 600 픽셀
- 스프라이트 시트 기준 데이터: 10종 동작, 총 76프레임

### 실행 방법

`Labs/LEC09` 폴더에서 `python sonic_animation_viewer.py`를 실행한다. Python 환경에 `pico2d`가 설치되어 있어야 하며, `sonic-sprite.png`는 실행 파일과 같은 폴더에 둔다.

## 2. 기능 요구사항

### FR-1. 화면 표시

- 프로그램 시작 시 1200 × 600 크기의 뷰어 창을 표시한다.
- 각 프레임은 스프라이트 시트의 원본 프레임 크기를 기준으로 가로·세로 각각 4배 확대한다.
- 캐릭터가 화면 경계를 벗어나거나 프레임이 잘려 보이지 않도록 배치한다.

### FR-2. 애니메이션 데이터

- 스프라이트 시트의 10개 동작과 총 76개 프레임을 등록해 재생한다.
- 각 프레임은 시트에서 해당 이미지 영역을 올바르게 잘라 표시한다. 프레임 영역은 이미지 경계 안에 있어야 한다.
- 동작의 재생 순서와 각 동작에 속한 프레임 목록을 명시적으로 관리한다.

### FR-3. 동작별 재생과 전환

- 각 동작의 프레임을 순서대로 재생하고, 해당 동작을 총 5회 반복한다.
- 5회 재생이 끝나면 마지막 프레임을 화면 중앙에 유지하며 1초간 정지한다.
- 정지 시간이 끝나면 다음 동작의 첫 프레임부터 재생한다.
- 마지막 동작 뒤에는 첫 동작으로 돌아가 위 과정을 무한 반복한다.

### FR-4. 동작에 따른 이동

- 10개 동작 중 첫 번째·세 번째·네 번째·마지막 동작을 제외한 6개 동작은 프레임 재생과 동시에 화면에서 좌우로 이동한다.
- 이동 속도는 실제 경과 시간을 기준으로 초당 180픽셀로 계산한다. 이동 방향에 맞춰 좌우 반전한다.
- 캐릭터 전체가 화면 안에 머물도록 좌우 경계에서 방향을 반전한다.
- 여덟 번째 점프 동작은 좌우 이동과 함께 최고 높이 120픽셀의 포물선형 수직 궤적을 그린다.
- 첫 번째·세 번째·네 번째·마지막 동작은 화면 중앙에서 재생한다.
- 각 동작을 5회 반복한 뒤의 1초 정지 동안 프레임과 위치를 유지한다. 동작 전환 시 이동 중인 캐릭터의 위치와 방향을 불필요하게 초기화하지 않는다.

## 3. 범위 및 제외 사항

- 실행 즉시 자동 재생하며, 사용자 입력 없이 전체 동작을 순환한다.
- 키보드로 동작을 직접 선택하거나 재생을 제어하는 기능은 이번 범위에 포함하지 않는다.
- 창 닫기 버튼 또는 `Esc` 키로 뷰어를 종료할 수 있다.
- 이미지 편집, 동작 추가, 설정 화면은 이번 범위에 포함하지 않는다.

## 4. 완료 및 검증 기준

- 지정한 파일 하나로 실행되며, 제공된 스프라이트 이미지를 불러와 1200 × 600 화면에 표시한다.
- 10개 동작의 프레임 수 합계가 76이고, 등록된 모든 프레임 영역이 이미지 안에 있다.
- 프레임이 원본 대비 4배 크기로 보이고 동작이 지정된 순서로 재생된다.
- 각 동작은 정확히 5회 재생된 뒤 1초간 마지막 프레임과 위치를 유지하고 다음 동작으로 전환된다.
- 이동 동작의 재생 중 X 좌표가 변하고, 좌우 경계에서는 방향과 스프라이트가 함께 반전된다. 전체 스프라이트가 화면 밖으로 잘리지 않는다.
- 점프 동작은 좌우 이동과 위아래 포물선 궤적을 함께 보인다. 첫 번째·세 번째·네 번째·마지막 동작은 중앙에서 재생된다.
- 반복 사이 정지 중에는 프레임과 위치가 유지되고, 이동 동작끼리 전환할 때 위치가 이어진다.
- 마지막 동작 다음에 첫 동작으로 자연스럽게 이어진다.
- 창 닫기 버튼과 `Esc` 키로 정상 종료되고 그래픽 창이 정리된다.
- 문법 검사와 실제 실행을 확인한다. 실행 중 동작별 프레임, 정지 구간, 중앙 위치 유지 및 순환을 관찰해 요구사항을 검증한다.

## 5. 단계별 개발 및 커밋

작게 구현하고 각 단계에서 확인한 뒤 커밋한다. 전체 개발 과정에서 의미 있는 변경을 최소 20회 커밋하며, 커밋 메시지와 로그로 구현 및 검증 이력을 확인할 수 있어야 한다.

1. 실행 창과 종료 처리를 구성한다.
2. 이미지 로딩과 4배 확대 표시를 확인한다.
3. 프레임 영역과 10개 동작 데이터를 등록하고 좌표 및 76프레임 합계를 확인한다.
4. 프레임 시간 기반 재생과 동작별 5회 반복을 구현한다.
5. 1초 정지와 다음 동작 전환, 전체 순환을 구현한다.
6. 이동 동작의 좌우 이동과 경계 반전, 점프 궤적 및 정지 동작의 중앙 배치를 구현한다.
7. 전체 실행을 반복 확인하고 문서의 완료 기준에 따라 최종 검증한다.
